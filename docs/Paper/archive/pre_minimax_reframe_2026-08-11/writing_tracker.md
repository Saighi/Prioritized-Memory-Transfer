**REPLAY vs REACTIVATION (D11, 2026-08-06) — four tiers, enforce everywhere:**
- *memory replay* = the biological phenomenon, used as an **umbrella term** and **explicitly defined as broad at first use** (abstract + Intro ¶2). The field is not consistent on this word, so we stipulate rather than assume.
- *prioritized memory reactivation* = **what our model produces**. Use this, not "replay", for model output.
- *reactivation of individual memories* = the **nonlinear (ReLU) extension** (Results 5).
- *sequential replay reproducing the temporal or spatial order of experience* = **NOT modelled**. Rectification buys cone confinement and discrete memories, it buys **nothing** about temporal order. **SCOPE EXPANDED 2026-07-27 — THE MODEL IS NO LONGER LINEAR-ONLY.** The mechanism was verified with **ReLU units (no bias) + non-negative patterns** (`ModelConfig(activation="relu", pattern_kind="nonneg")`, `mode="full"`). Consequences for the paper:

- **Why the linear analysis still covers the rectified net:** with ReLU and no bias the network is *exactly* linear within a fixed activation pattern (inactive columns of W zeroed), so the linear theory is the **within-cone description**, one copy per cone. Not an approximation.
- **Load-bearing condition: `f(m_p) = m_p`** (exposed as `info.patterns_fixed`). Holds for identity and for rectifying f with non-negative patterns. Then `m_p = W_T m_p` still, `build_memory` unchanged, `ker(I−W_T)` really is the memory manifold. The memory *subspace* becomes the patterns' convex **cone** (negative combinations leave the orthant and acquire error) — this is what kills mixture states.
- **Honest costs/caveats (do NOT overclaim):** ReLU holds memories ~**2x looser** than linear (d=48,P=3: total novelty 0.088 vs 0.023; ‖W_S−W_T‖ 0.49 vs 0.23). Prioritization is **sharper** (threshold-crossing times spread ~3–4x wider). The robust seed-stable signature is **cone confinement** (fraction of time any coefficient c_p<0: relu 7%, linear 100%, tanh 99%). Run-**averaged** replay sharpness (participation ratio) is seed-dependent and NOT a reliable discriminator, and is decoupled from recall quality (relu is sharpest yet recalls worst) — but see the TIME-RESOLVED framing under Results 5: the average hides a real early(point-memory)/late(mixture) structure, so the claim should be made time-resolved rather than abandoned.
- **tanh trap:** tanh at unit amplitude is **indistinguishable from linear** (components ~0.1, deviation ~0.3%) so it does NOT test saturation; the earlier "saturating units break it" claim was a `pi_ST="auto"` confound. Claim scope is precisely: ReLU + non-negative patterns, i.e. wherever `f(m_p)=m_p`. Do NOT claim "works for nonlinear activations" generally.
